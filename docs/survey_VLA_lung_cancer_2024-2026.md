# VLA / 多模态大模型 × 肺癌：近两年研究调研（2024–2026）

> 范围说明：近两年（2024–2026）与"VLA / VLM / 多模态大模型"和"肺癌"相关的代表性研究。
> 注意：以下条目均来自公开检索结果，引用细节（卷期页码、作者顺序）建议投稿前用原文二次核对。

## 1. 概念界定

| 缩写 | 全称 | 说明 | 代表模型 |
|------|------|------|----------|
| LLM | Large Language Model | 纯文本大模型 | GPT 系列、DeepSeek |
| VLM | Vision-Language Model | 视觉+语言，做影像理解/报告/问答 | GPT-4o、BiomedCLIP、MedGemma、Merlin |
| VLA | Vision-Language-Action Model | VLM + 动作输出，感知—决策—执行闭环 | RT-2、OpenVLA、OpenVLA-OFT、π0、GR00T |

**关键结论**：肺癌领域目前的研究绝大多数属于 **VLM/LLM**（影像理解、报告生成、分期抽取）；严格意义的 **VLA**（输出机器人动作）在肺癌场景仍属空白/萌芽期，主要相邻证据来自**机器人支气管镜、CT 引导穿刺机器人、手术导航**等介入场景。这正是本项目的机会点。

## 2. 肺癌 + VLM / 多模态大模型研究（主流方向）

### 2.1 肺结节结构化表征与诊断决策

- **FZ-VLM（2026, arXiv:2608.15006）**
  两阶段 Florence-Zephyr 视觉语言模型框架，用于肺 CT 结节的统一结构化表征：
  - Stage 1：微调 Florence-2 从 2D 轴位 CT 切片提取放射学属性（解剖位置准确率 77.18%、边缘特征 67.96%、密度类型 79.13%，直径估计 MAE 2.58 mm），优于 GPT-4 基线与人类基线；
  - Stage 2：Zephyr-7B 基于属性生成结节描述、随访建议与纵向分析，专家评估准确率 93.9%、完整性 98.6%。
  - 声称是**首个**用于结构化结节表征与临床决策的两阶段 VLM 框架。

- **GPT-4.1 / GPT-4o 用于 3D CT 肺癌诊断（2025, Health Information Science and Systems, DOI: 10.1007/s13755-025-00417-8）**
  Shi Ning 等提出基于无损 3D CT 图像的 VLM 流程，做患者级别的良恶性评估。

- **GPT-4V 纵向 CT 肺结节评估（2025, Cell Reports Medicine, 6(3):101988）**
  Mao YQ 等：用 AI 聊天机器人基于**纵向（多次随访）CT** 评估肺结节，验证 LLM/VLM 在随访场景的能力。

- **低剂量 CT 肺癌风险深度学习外部验证（2025, Radiology, 316(2):e243393）**
  Lee JH 等（非 VLM，但属《肺结节精准管理专家共识(2026)》引用的代表性筛查模型）。

### 2.2 报告生成 / 分割一体化

- **广东工业大学（2026, 广东工业大学学报）**：基于 VLM 的肺部影像病灶分割 + 报告生成统一框架；分割 Dice 85.42%，解剖定位准确率 84.12%，结节类型分类 85.56%。
- **OmniCT（2026, arXiv:2602.16110）**：统一的"切片-体积" CT 大视觉语言模型（LVLM），通过空间一致性增强 + 器官级语义增强解决 2D/3D CT 理解碎片化问题，构建 MedEval-CT 基准。
- **DM-RRG（2025, Medical Image Analysis）**：疾病主题引导 + 多粒度图文对齐的放射报告生成（通用，可用于胸部影像）。

### 2.3 肺部影像基础模型（VLM 的底座）

- **LCTfound / Lung CT Vision Foundation Model（2025, Nature Communications）**
  清华、复旦、广医一院等：大规模自监督预训练的肺部 CT 视觉基础模型，覆盖诊断与影像处理多任务；训练数据来自 5 家医院，天河二号训练。
- **BiomedCLIP（CVPR 2025 引用活跃）**：1500 万生物医学图文对预训练的多模态基础模型，常用于肺结节/胸片下游任务。
- **MedGemma 1.5（Google, 2026-01）**：开源医疗多模态基础模型，支持纯文本/单图/多图问答，可本地部署，适合作为肺癌 VLM 项目的候选底座。
- **KEEP（上海交大等）**：知识增强病例基础模型，用疾病知识图谱做预训练，覆盖癌症诊断（含肺癌相关病理）。

### 2.4 LLM 处理肺癌文本/分期

- **Kim B 等（2024, JMIR Med Inform, 12:e67056）**：微调 CoT 的 LLM 从肺癌手术病理报告自动预测 TN 分期并生成依据。
- **Cho H 等（2024, J Biomed Inform, 157:104720）**：生成式语言模型抽取肺癌分期描述符。
- **Tozuka R 等（2025, Jpn J Radiol, 43(4):706-712）**：NotebookLM（RAG 型 LLM）用于肺癌分期。

### 2.5 多模态融合（病理 + 基因组 + 影像）用于肺癌预后/疗效

- **《人工智能应用于肺癌筛诊疗的专家共识（2026版）》**（MedSci 转载）：系统梳理 AI 在肺癌筛查、诊断、治疗的应用；强调融合病理图像（H&E、免疫组化）、基因组（NGS、TMB、MSI）与临床变量构建多模态复合模型，预测靶向/免疫治疗反应。
- **Pathomic Fusion**（经典引用）：病理 + 基因组特征融合的预后/疗效预测框架。
- **He 等**：CT 影像 + TMB 联合建模预测免疫检查点抑制剂疗效。
- **SMILE（2025, IEEE TMI, 44(8):3151-3161）**：基于多次 CT 扫描的顺序多示例学习肺癌筛查分类框架。
- **CoLM（2025, Biomed. Signal Process. Control., 100:107097）**：对比学习 + 多示例学习，基于冰冻病理图像的肺癌手术方案分类。

## 3. 肺癌 + VLA 相邻场景（机器人介入 / 导航）

严格意义的"VLA + 肺癌"论文目前极少，以下为最接近的落地方向：

### 3.1 机器人支气管镜（Robotic Bronchoscopy）
- 2026 年国内多家医院报道：机器人支气管镜 + 导航系统 + 术中 CBCT，实现外周肺结节的"指哪打哪"活检；导管外径约 3.5 mm，可达 7 级以上支气管。
- 临床痛点（=VLA 机会）：导航与术中实际存在 **CT-to-body divergence**（术前 CT 与术中真实解剖偏差），目前靠人工 + CBCT 校正——**自动化的"感知-校正-动作"正是 VLA 范式**。

### 3.2 CT 引导经皮穿刺机器人
- **《穿刺手术机器人辅助经皮肺穿刺诊疗技术临床规范化应用专家共识》（2025, 中华胸部外科电子杂志, 12(1):1-11）**
- 国产小型结节定位机器人（2026 报道）：单次术前 CT 扫描 → AI 病灶识别 → 三维重建 → 智能路径规划 → 机械臂亚毫米级动态导航定位。
- You X 等（2025, J Cancer Res Ther, 21(2):389-394）：机器人辅助导航系统在胸腹部肿瘤 CT 引导穿刺中的安全性与有效性。

### 3.3 手术导航与 AR 引导
- 清华王广志团队等：多模态图像引导 + 运动规划的机器人微创治疗系统；AR 引导穿刺（Virtual Reality 2025）等，为 VLA 的"视觉伺服"提供技术栈参考。

## 4. 通用 VLA 模型谱系（可迁移到医疗场景的底座）

| 模型 | 年份 | 特点 |
|------|------|------|
| RT-2（Google） | 2023 | 开山之作，动作作为 token 输出 |
| OpenVLA（Stanford） | 2024 | 开源权重 + 微调链路完整，适合二次开发 |
| OpenVLA-OFT | 2025 | 并行解码 + 连续动作，提升速度与精度 |
| π0 / π0.7（Physical Intelligence） | 2024-2026 | Flow Matching / 动作分块，连续动作生成 |
| GR00T（NVIDIA） | 2025 | 人形机器人通用 VLA |
| RIPT-VLA（2025） | 2025 | 交互式后训练范式，缓解离线模仿学习局限 |
| DriveTeach-VLA（北航/清华, ECCV 2026） | 2026 | 用图像轨迹打通规划与多模态基座（自驾场景，方法论可借鉴） |

VLA 的共性挑战（对医疗场景同样成立）：**动作数据稀缺、多模态对齐难、长时序决策、安全约束强**——医疗场景安全约束更强，需要引入专家审核/规则护栏。

## 5. 研究空白与可切入方向

> **范围约束（2026-08-21 确认）：项目初期不涉及硬件。** 机器人支气管镜导航、CT 引导肺穿刺等硬件 VLA 方向（原方向 1、2）暂缓，仅作背景参考。

在纯软件/数据驱动路线下，可切入方向：

1. **soft-VLA：临床动作预测（推荐，保留 VLA 定位）**：将 "Action" 定义为临床决策动作——活检建议、随访间隔（3/6/12 月）、治疗方案选择（手术/靶向/免疫/观察）。输入为 CT 影像 + 报告文本，模型直接输出"下一步临床动作"。与 FZ-VLM（只到随访建议文本）相比，这是把 VLM 升级为可执行动作空间的最短路径；数据可用 LIDC-IDRI、NLST 等公开数据集的随访标注。
2. **闭环诊疗 Agent（Agentic VLM）**：把"筛查→结节表征→随访建议→报告生成"做成可执行工作流（FZ-VLM、OmniCT 已提供组件）。
3. **多模态疗效预测**：CT + 病理 + 基因组融合预测免疫治疗反应（2026 专家共识明确支持的热点）。
4. **纵向随访 VLM**：多次 CT 对比的结节演变分析（对标 Cell Rep Med 2025 的 GPT-4V 工作，但用开源模型做可复现版本）。
